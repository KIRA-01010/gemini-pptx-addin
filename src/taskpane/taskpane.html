Gemini Slides

Stored only in this browser's local storage, never sent anywhere but Google's Gemini API. Get a key at aistudio.google.com/apikey.

New slides are added to the end of your current presentation. If you started from a blank deck, just delete the leftover blank first slide afterward — deleting slides automatically turned out to be unreliable on PowerPoint for the web, so this add-in doesn't attempt it.
